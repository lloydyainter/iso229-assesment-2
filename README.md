# ISO229 Assessment 2 – HTML5 Website

## Project
Brian Bell Home Centres – Customer Information Website

## Purpose
This is an individual student-developed multi-page HTML5 website created for ISO229 Web Design Assessment 2.

The website provides:
- a home/introduction page;
- product and service information;
- a customer enquiry form;
- semantic HTML5 structure;
- images with alternative text;
- a table;
- accessible form labels and HTML5 validation;
- consistent navigation between pages.

## Target audience
Customers who want basic information about home appliances, furniture, technology and entertainment products and who want to make a product enquiry.

## Pages
1. `index.html` – Home
2. `services.html` – Products & Services
3. `contact.html` – Contact / Enquiry

## Technologies
- HTML5
- Basic CSS3
- Visual Studio Code or another approved text editor
- Git
- GitHub
- GitHub Pages

No Bootstrap, Tailwind, WordPress, Wix or downloaded template is used.

## Accessibility
The website includes:
- `lang="en"`
- meaningful page titles
- logical heading hierarchy
- semantic elements
- descriptive image alt text
- figure and caption
- labels connected to form controls
- appropriate HTML5 input types
- required/minlength/maxlength validation
- table headings using `scope`
