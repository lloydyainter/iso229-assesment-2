# ISO229 Assessment 4 – Project Summary

## Brian Bell HomeCentres – Customer Information Website

### 1. Website purpose
This project is an integrated continuation of the website developed for ISO229 Assessments 2 and 3. Its purpose is to provide a simple, responsive customer information website for a Brian Bell HomeCentres academic scenario. The website presents general information about home appliances, furniture and home products, technology, entertainment products and customer enquiries. It is clearly identified as a student academic project and is not an official company website.

### 2. Target audience
The target audience is customers who want to explore general product categories, identify what type of product they are interested in and prepare an enquiry before visiting or contacting a store. The interface is designed for people using mobile phones, tablets and desktop computers.

### 3. Main website features
The website contains three semantic HTML5 pages: Home, Products & Services, and Contact / Enquiry. CSS3 provides the visual design using Flexbox, CSS Grid, responsive units and media queries. The pages include responsive navigation, cards, a product information table, a substantial enquiry form, visible keyboard focus states, labels, alternative text and readable colour contrast. The layout adapts between mobile, tablet and desktop screen sizes.

### 4. JavaScript functionality
Three meaningful JavaScript interactions were implemented. First, the Products & Services page provides live product-category searching and category filtering, with a result count and clear-filter button. Second, accessible FAQ accordion controls allow users to expand and collapse answers without leaving the page. Third, the enquiry form uses JavaScript together with HTML5 validation to check required fields and display a confirmation or error message. Local storage also remembers the visitor's previously selected product category on the enquiry page.

### 5. Testing performed
The project is designed to be tested functionally by checking all navigation links, search/filter controls, FAQ buttons, form controls and JavaScript messages. Responsive testing should be completed at approximately 375×812, 768×1024 and 1366×768. Browser testing should be completed in two modern browsers such as Microsoft Edge and Google Chrome. HTML and CSS validation, keyboard navigation/focus and a Lighthouse or equivalent accessibility check should also be recorded in the evidence folder.

### 6. Known limitations and future improvements
The enquiry form is a front-end academic demonstration and does not submit information to a real business database or email service. Future work could connect the form to a secure backend, add real product data, improve image content and provide a production contact system.
